# Contribuir

Gracias por ayudar a mejorar el proyecto.

## Antes de empezar

1. Comprueba que no exista ya una incidencia o pull request equivalente.
2. Mantén los cambios pequeños y centrados en un único objetivo.
3. Evita añadir dependencias cuando la plataforma web o el código existente sean suficientes.

## Desarrollo

```bash
pnpm install
pnpm dev
```

Antes de enviar un pull request, ejecuta:

```bash
pnpm check
pnpm build
```

Describe qué problema resuelve el cambio y cómo se ha comprobado. Para cambios visuales, añade una captura si ayuda a revisar el resultado.
